# Plain language

1. Find the one thing the reader must understand. Put it first.
2. Use short sentences, one idea each. Aim for 15 words or fewer.
3. Replace jargon with everyday words. If a technical term is unavoidable, explain it once.
4. Use "you" for the reader and active verbs ("We will send" not "It will be sent").
5. End with what the reader should do next, if anything.

Return only the rewritten text, then one line starting with "Changed:" that lists what you changed.
